## 総合評価（A〜D + 一言）

**B（よく噛み砕けている。あと一段の「用語の先出し言い換え」と、第4章・付録の段差緩和で A に届く）**

Scratch 対応表・マトリョーシカ・螺旋の手計算表・「止める＝空」vs「止める＝葉」など、高校生向けの足場は全体として強い。弱点は、概念が固まる前に専門用語（データ駆動／Headless／構造的再帰／宣言型）が先に立つ箇所と、第4章後半（シェルピンスキーの復帰命令・ドラゴン・plot コラム）および付録 F/D の読者層ギャップ。

## よくできている点

- **Scratch → 括弧の対応**（序章・第1–2章）が具体的で、文法恐怖を下げている。
- **第3章の螺旋手計算表**（times が減る様子）は、再帰の「なぜ止まるか」を高校生が自力で追える最良の仕掛け。
- **第4章の「第3章との対比」箱**（基底で `empty` vs `leaf`）は、よくある「深さ0で何も出ない」混乱を先回りしている。
- **木の `forward (- size)` 説明**（状態＝位置と向き）は、再帰合成の本質を体感レベルで伝えている。
- **付録B** の Windows 手順・つまずきポイントは、夏休みの高校生が一人で環境を立てる用途に十分噛み砕けている。
- 各章扉の「ゴール／想定読者／付属コード」が揃っており、読み進めの見通しが良い。

## PR向け最小改善リスト

1. **第4章**: `triangle-outline` を `sierpinski` より前へ。復帰移動を3ステップの言葉（または小図）に分解。ドラゴンに depth 0→1→2 の折り表を1つ。
2. **第4章 plot コラム**: 本編は「ノード数の棒グラフで爆発を見る」に縮小。Composability / Headless / 3D 売りは付録 F へ。
3. **第3章**: 本線は `append` の spiral に寄せ、`cons`/`spiral2` は「入れ子になる発展」注か付録Cへ。
4. **第2章 §2.0**: ボディ・シントニック削除（または一言化）。手続き型／データ駆動は日常語を先に。
5. **序章表・終章・付録F**: Headless／宣言的／第一級…を平易語に置換。付録F冒頭に「発展・任意」ラベル。
6. **第1章**: 見出しから「ポーランド記法」を外す。`my-length` に2行の追跡例。
7. **付録D/E**: 高校生向けリンクと著者用メモを分離。E.2 の検討メモ口調を本文から外す。
8. **付録C**: デザインレシピ1行を日常語化（任意で「できた合図」を添える）。

## 著者判断が必要な点

- **ドラゴン曲線の深さ**: 本編必須か、「動かすだけ・仕組みは★」か。薄い説明のまま必須にすると消化不良になりやすい。
- **plot を第4章本線に残すか**: 再帰の「爆発」直感には有用だが、現状の売り文句密度だと読者層が切れる。コラム残存範囲は編集判断。
- **言語方針 A の見せ方**: 付録Eを読者向けガイドに徹するか、方針検討の記録も残すか。
- **`cons` パターンを本編で教えるか**: 公式 turtle 例や後続学習との接続を優先するなら残し、高校1週間コースなら `append` 一本化が安全。
- **付録Dの issue / 旧ドラフト**: 公開書籍に含めるか、リポジトリ README のみにするか。
