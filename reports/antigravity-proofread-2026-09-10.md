# Antigravity 校正報告

## 要約（全体の印象・優先度の高い問題）

本書は、Scratch から Racket（関数型言語）へとステップアップしながら「論理」「データ駆動」「再帰」「フラクタル図形」を学ぶ高校生・初学者向けの優れた技術書ドラフトです。Scratch のブロックと Racket の括弧構造の対比や、マトリョーシカ人形を用いた再帰の例えなど、極めて分かりやすく丁寧な解説が展開されています。

校正の観点から見つかった主な改善点・優先度の高い問題は以下の通りです：

1. **【重要度：高】付録B のサンプルコードにおける API 名不一致と動作不可**
   - `appendix-b-environment.md` の `square1` コード例で `(right 90)` という関数が使われていますが、第2章および `racket-turtle` ライブラリの正記は `(turn-left 90)` または `(turn-right 90)` です。このまま実行するとエラーになる可能性があるため、第2章のコードと同一の表記に修正が必要です。
2. **【重要度：高】編集用作業メモの残存**
   - `appendix-b-environment.md` / `appendix-d-references.md` / `appendix-e-lang-policy.md` の末尾に `> 三角ロジックで整理予定` という執筆時メモが残っているため削除が必要です。
3. **【重要度：中】表記の不統一（「カメ」と「亀」、DrRacket の設定箇所など）**
   - 本文中で一貫して「カメ」と表記されていますが、`appendix-e-lang-policy.md` にのみ「亀」という漢字表記が混在しています。
   - `intro.md` と `appendix-b-environment.md` で DrRacket の設定タブの案内（`Display` タブ vs `Editing → General Editing`）に不統一が見られます。
4. **【重要度：中】誤字脱字・表現の微修正**
   - `intro.md` に「のデータことを」という文法誤植があります。

### appendix-b-environment.md
- 重要度: 高
- 箇所: `#### B.6 teachpacks（racket-turtle）の導入`
- 現状:
```racket
(define square1
  (list
   (forward 100)
   (right 90)
   (forward 100)
   (right 90)
   (forward 100)
   (right 90)
   (forward 100)))
```
- 提案:
```racket
(define square1
  (list
   (forward 100)
   (turn-left 90)
   (forward 100)
   (turn-left 90)
   (forward 100)
   (turn-left 90)
   (forward 100)
   (turn-left 90)))
```
- 理由: `racket-turtle` の正しい標準プロシージャ名は `turn-left` / `turn-right` です。また第2章 L70 のコード例と整合性を保ち、正しく正方形が閉じるように4回目の回転を追加するため。
