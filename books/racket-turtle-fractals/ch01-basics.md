#### 1.1 式・評価・基本データ

##### 🔍 用語解説: 「式」「評価」「値」ってなに？
プログラミングの世界には、最初に覚えておくと一気に見通しが良くなる3つの基本用語があります。

- **値（Value）**: これ以上計算できない完成したデータ（例: 数値 `123`、文字列 `"hello"`、真偽値 `#true`）。
- **式（Expression）**: 計算を実行すると「値」になるコードの固まり（例: `(+ 2 4)` や `(* 3 3)`）。
- **評価（Evaluation）**: 式を実行して「値」に落とし込む計算プロセスのこと（例: `(+ 2 4)` を評価すると `6` になる）。

##### 🧱 基本データ型（値の種類）
Racket には、最初から用意されている基本データ型（値の種類）があります。

```racket
123          ; 数（Number）
"hello"      ; 文字列（String）
#true        ; 真（Boolean: 正しい）
#false       ; 偽（Boolean: 間違い）
```

※ Scratch でいうと、数入力フォームに入れる数字、文字フォームに入れるテキスト、そして `[ (a) > (b) ]` などの条件ブロックが返す「本当(true)/嘘(false)」に対応します。

##### ➕ 式と「前置記法（ポーランド記法）」
数学では `1 + 2` のように演算子を数字の真ん中に挟みます（中置記法）。しかし Racket では演算子を**かっこの一番最初**に書きます（**前置記法**）。

```racket
;; 規則: (演算子 引数1 引数2 …)
(+ 2 4)                  ; => 6
(* 3 5)                  ; => 15
(+ 2 4 (* 3 6 (+ 1 1)))  ; => 内側から評価されて 42
```

###### 💡 なぜ前置記法なのか？（Racket の強み）
1. **何個でもまとめて足せる！**: 中置記法だと `1 + 2 + 3 + 4 + 5` と＋を何度も書く必要がありますが、前置記法なら `(+ 1 2 3 4 5)` と書くだけで一発で計算できます。
2. **Scratch のブロックと同じ構造**: Scratch の `[ ( ) + ( ) ]` ブロックに数値を入れる感覚と全く同じです。括弧 `(` がブロックの外枠、先頭の `+` がブロックの種類を表しています。

#### 1.2 定数と関数、`check-expect`

##### 📌 定数 `define`——値に分かりやすい名前をつけよう
プログラムの中に `450` や `15` といった生の数字（マジックナンバー）を直接いくつも書くと、後から見返したときに何の値かわからなくなってしまいます。Racket では `define` を使って値に名前を付けます。これを **定数（Constant）** と呼びます。

```racket
(define WIDTH 30)
(define HEIGHT 20)
(define CELL-SIZE 15)

;; 定数を使って画面幅を計算する
(define BOARD-PIXEL-WIDTH (* WIDTH CELL-SIZE))  ; => 450
```

慣習として、ずっと値が変わらない定数には `WIDTH` や `CELL-SIZE` のように **大文字** を使います。

##### ⚙️ 関数 `define`——「名前を付けた計算の機械」を作ろう
数学の $y = f(x)$ や、Scratch の **「定義する (Make a Block)」** ブロックと同じように、入力（引数）を受け取って結果（返り値）を返す仕組みを **関数（Function）** と呼びます。

```racket
;; 構文: (define (関数名 引数1 引数2 …) 本体の式)

;; square-of: 数 x を受け取り、x の2乗を返す関数
(define (square-of x)
  (* x x))

;; greet: 名前（文字列）を受け取り、挨拶文を返す関数
(define (greet name)
  (string-append "Hello, " name "!"))
```

- `(square-of 8)` を評価すると、`(* 8 8)` が計算されて `64` が返ってきます。
- `(greet "Racket")` を評価すると、`"Hello, Racket!"` が返ってきます。

##### ✅ `check-expect`——自動テストでバグを撃退しよう！
プログラミングで一番困るのは、「自分で書いた関数が本当に正しく動いているか分からない」ことです。普通なら手動で毎回数字を入れて確認しますが、プログラムが大きくなると大変です。

そこで BSL には **`check-expect`** という素晴らしい仕組みが用意されています。

```racket
;; (check-expect (関数の呼び出し) 期待される正しい結果)
(check-expect (square-of 8) 64)
(check-expect (greet "Racket") "Hello, Racket!")
```

コードを書いたら **Run** ボタンを押すだけ！DrRacket が裏で自動的にすべてのテストを実行し、1つでも計算結果が違っていたら「ここが違うよ！」と教えてくれます。この仕組みを **自動テスト（Unit Testing）** と呼び、現代のプログラミング開発には欠かせない必須スキルです。

#### 1.3 条件分岐（`if` と `cond`）

##### 🔀 用語解説: 「条件分岐」「述語（Predicate）」
状況に応じて処理を変える仕組みを **条件分岐** と呼びます。Scratch でいう `[もし〜なら...]` ブロックです。

また、真偽値（`#true` または `#false`）を返す関数のことを、プログラミングでは **述語（Predicate）** と呼びます。Racket では慣習として、述語関数の名前の末尾に `?` を付けます（例: `string=?`, `zero?`, `draw-more?`）。

##### 🌿 `if` 式と `cond` 式
Racket には条件分岐を書く方法が2つあります。

###### 1. `if` 式（2択の分岐）
```racket
;; 構文: (if 条件式 真のときの結果 偽のときの結果)
(if (string=? "hi" "bye") "yarr" "meow")  ; => "meow"
```

###### 2. `cond` 式（多段階の分岐）
Scratch で「もしAなら… そうでなくもしBなら…」とブロックを何重にもネストすると、右側にどんどん伸びて見づらくなりますね。Racket の **`cond`** を使えば、何段階もの条件を括弧 `[条件 結果]` でスッキリ並べることができます。

```racket
(define ran-num 3)

(cond
  [(< ran-num 3) "<3"]
  [(= ran-num 3) "equal"]   ; => "equal"
  [else "other"])
```

###### 🌲 フラクタル描画での活用例
第4章のフラクタル描画では、「再帰の深さ `depth` がまだ残っているか？」を判定する条件分岐が命になります。

```racket
;; 再帰の深さ depth が 0 より大きいか？（述語）
(define (draw-more? depth)
  (> depth 0))

;; 枝の長さ length が最小長 min-len 以上か？（述語）
(define (branch-ok? length min-len)
  (>= length min-len))

;; 両方の条件を満たすときだけ、次の枝を描く
(define (continue-fractal? depth length min-len)
  (if (draw-more? depth)
      (branch-ok? length min-len)
      #false))
```

#### 1.4 リストのさわり（タートルへの命令列を作る準備）

##### 📜 用語解説: 「リスト（List）」とは？
Scratch にも「リスト」というブロックがありましたね。数や文字などの複数のデータを、順番通りに1つのグループとして並べたものを **リスト（List）** と呼びます。

タートルグラフィックスでは、「100進む」「90度右に回る」「100進む」といった**一連の命令の並び**をリストとして作成し、それをカメに渡して図形を描かせます。

##### 🛠️ リストの基本操作（`list`, `first`, `rest`, `empty?`）
BSL では、リストを作る・調べるために以下の基本関数を使います。

- `(list a b c)` ── 要素 `a, b, c` を並べたリストを作る
- `empty` ── 中身が1つもない空のリスト
- `(first lst)` ── リストの**先頭（一番最初）の要素**を取り出す
- `(rest lst)` ── リストの**先頭を除いた「残りのリスト」**を取り出す
- `(empty? lst)` ── リストが空かどうかを判定する（述語）

```racket
;; 正方形を描くためのステップ（距離・角度の並び）の例
(define SQUARE-STEPS (list 100 90 100 90 100 90 100 90))

(first SQUARE-STEPS)  ; => 100 (最初の歩数)
(rest SQUARE-STEPS)   ; => (list 90 100 90 100 90 100 90) (残りのリスト)
```

##### 🔄 リスト処理の基本パターンと「再帰」（チラ見せ）★第3章で本格的に学ぶ

リストを扱う関数を作るとき、よく使うパターンがあります。それは **「先頭と残りに分けて、残りをまた同じ関数に渡す」** というものです。リストの要素の個数（長さ）を数える関数を例に見てみましょう。

```racket
;; my-length: リスト xs の長さを計算する関数
(define (my-length xs)
  (cond
    [(empty? xs) 0]                        ; 1. 空リストなら長さは 0
    [else (+ 1 (my-length (rest xs)))]))   ; 2. そうでなければ「1 + (残りの長さ)」
```

`else` の中で自分自身の関数 `(my-length (rest xs))` を呼び出しているのが分かりますか？ これが **再帰（Recursion）** です！

**今は「おお、自分を呼んでる！」と眺めるだけでOKです。** この関数をきちんと設計する手順（基底条件・再帰ステップの型紙）は**第3章**でじっくり学びます。ここでは次の3点だけ覚えておきましょう:

1. リストは「**先頭 + 残り**」に分けられる
2. **残りもまたリスト**である（`(rest xs)` の型はリスト）
3. 空リスト `empty` に行き着くと終わり

第3章の冒頭では、この「自分を呼ぶ」仕組みをマトリョーシカ人形の比喩とともに、もう少しゆっくり解きほぐしていきます。楽しみにしていてください！
