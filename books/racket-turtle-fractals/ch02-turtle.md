#### 2.0 タートルグラフィックスの歴史と「データ駆動」の約束

##### 🐢 タートルグラフィックスってどこから来たの？
「画面上のカメ（タートル）を動かして図形を描く」というアイデアは、今から半世紀以上前の1960年代、マサチューセッツ工科大学（MIT）の **シーモア・パパート（Seymour Papert）教授** らによって開発された教育用言語 **Logo** で誕生しました。

パパート教授は、「子どもたちが『もし自分が画面のカメになったら、どう動けばいいだろう？』と自分の体の感覚（ボディ・シントニック：身体を介した同型的な学び）を使って楽しく幾何学とプログラミングを学べるように」という願いを込めてタートルを作りました。この思想は、後に LEGO マインドストームや Scratch のペン機能へ受け継がれています。

##### 💡 Racket ならではの考え方: 「命令を実行する」のではなく「指示書データを作る」
Scratch のペン機能では、`[10 歩動かす]` ブロックを置くと、その瞬間にキャラクターが画面上を動きます。これを **手続き型（Procedural）** の描画と呼びます。

一方、Racket ではひと味違います。いきなりカメを動かすのではなく、**「カメに対する移動命令のリスト（指示書データ）」** を先にプログラミングで作ります。そして最後に `(draw 命令リスト)` を呼んで、一気にカメを走らせます。

このように、プログラムの主役を「操作の手順」ではなく「データ構造」に置く考え方を **データ駆動（Data-Driven）** と呼びます。

**第1章との違いを整理しておきましょう**（同じ「リスト」でも、中身が違います）:

| | 第1章のリスト | 第2章のリスト (`CommandList`) |
|---|---|---|
| 中身 | **数**（歩数・角度） | **命令**（カメへの指示） |
| 例 | `(list 100 90 100 90)` | `(list (forward 100) (turn-left 90))` |
| 何に使う | 正方形の「寸法」を表す | カメが実行する「指示書」 |

`list` / `first` / `rest` の操作は同じなので、第1章の感覚がそのまま生きています。変わるのは「リストに入っているものの種類」だけです。

| 段階 | デザインレシピ | タートルでの具体的な意味 |
|---|---|---|
| 1. **データ定義** | `CommandList` | カメが実行する命令のリスト `(list (forward 100) (turn-left 90) ...)` |
| 2. **データの意味** | 指示書 | 「カメが頭から順番に1個ずつ読み込んで実行するレシピ」 |
| 3. **関数化** | パラメータ化 | 1辺の長さや角の数を引数にして、どんな多角形でも量産できるようにする |

#### 2.1 `racket-turtle` の基本操作

##### 🛠️ コマンド一覧表
`racket-turtle` ライブラリで使う主な命令（コマンド）を見てみましょう。

| コマンド | 意味 | Scratch での対応 |
|---|---|---|
| `(forward x)` | x ピクセル前進する（負の数なら後退） | `[ (x) 歩動かす ]` |
| `(turn-left a)` | a 度 左へ向く | `[ (a) 度回す (左) ]` |
| `(turn-right a)` | a 度 右へ向く | `[ (a) 度回す (右) ]` |
| `(repeat k cmd-list)` | 命令リスト `cmd-list` を k 回繰り返す | `[ (k) 回繰り返す ]` |
| `(pen-up)` | ペンを上げる（線を引かずに移動） | `[ ペンをあげる ]` |
| `(pen-down)` | ペンを下ろす（線を引く） | `[ ペンをおろす ]` |
| `(change-color c)` | ペンの色を `c` に変更する | `[ ペンの色を (c) にする ]` |
| `(change-pen-size w)` | ペンの太さを `w` ピクセルにする | `[ ペンの太さを (w) にする ]` |
| `(draw cmds)` | 命令リスト `cmds` を実行して画面に描画 | (緑の旗を押して実行) |

##### 📐 正方形を描く指示書を作ってみよう
「100進んで、90度左に曲がる」を4回繰り返せば正方形になりますね。

```racket
#lang racket
(require teachpacks/racket-turtle)

;; 正方形の指示書（CommandList）を作る
(define square1
  (list
   (forward 100) (turn-left 90)
   (forward 100) (turn-left 90)
   (forward 100) (turn-left 90)
   (forward 100) (turn-left 90)))

;; カメを走らせて描画する！
(draw square1)
```

#### 2.2 正方形・正三角形・正多角形をつくる関数

##### 📐 数学の復習: 正多角形と「外角（Exterior Angle）」
カメが多角形を描くとき、回転させる角度は**内角ではなく外角**です！

正 $n$ 角形を一周描いて元の向きに戻ってくるとき、カメは合計で $360^\circ$ 回転します。したがって、1回の角で曲がる外角の大きさは次の一発の公式で求まります。

$$\text{外角} = \frac{360^\circ}{n}$$

- **正三角形 ($n=3$)**: 外角 $= 360 / 3 = 120^\circ$
- **正方形 ($n=4$)**: 外角 $= 360 / 4 = 90^\circ$
- **正六角形 ($n=6$)**: 外角 $= 360 / 6 = 60^\circ$

##### ⚙️ どんな多角形も作れる関数 `regular-polygon`
「1辺の長さ `len`」と「角の数 `n`」を引数に受け取り、正 $n$ 角形の指示書を自動生成する関数を作ってみましょう。

```racket
;; 1辺を描いて外角だけ左に回るパーツ
(define (side len exterior-deg)
  (list (forward len)
        (turn-left exterior-deg)))

;; 正 n 角形を作る関数
(define (regular-polygon len n)
  (repeat n (side len (/ 360 n))))
```

たったこれだけで、正六角形も正100角形（ほとんど円！）も自由自在に描けるようになります。

```racket
;; 一辺 80 の正六角形を描く指示書
(define hexagon (regular-polygon 80 6))

(draw hexagon)
```

#### 2.3 色・ペン・スタイルの装飾

見た目を鮮やかに装飾する命令も、すべて `CommandList` の中に含めることができます。

```racket
(define fancy-polygon
  (list (change-bg-color "black")      ; 背景を黒にする
        (change-color "gold")          ; 線を金色にする
        (change-pen-size 4)            ; ペンを太さ 4 にする
        (regular-polygon 70 8)))       ; 正八角形を描く
```

（※付属コード `code/ch02-turtle.rkt` には、同じ装飾を「正方形」に施した `fancy-square` が載っています。形とペン太さが違いますが、**「装飾命令リスト + 図形命令リスト」という構造は同じ**です。ここでは説明のため正八角形で示しました。）

##### 🎨 `append` によるリストの合成
装飾の命令リストと図形の命令リストは、Racket の **`append`** 関数を使えば簡単にがっちゃんこ（連結）できます！

```racket
(define (decorate style shape)
  (append style shape))
```

命令もスタイルもどちらも「リスト（`CommandList`）」なので、レゴブロックのように好きな順番で繋ぎ合わせることができます。
