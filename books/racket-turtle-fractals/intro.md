#### 0.1 自己相似形（フラクタル）入門——自然の中に潜む魔法の形

##### 🍃 ロマネスコと雪の結晶を見たことがありますか？
スーパーの野菜売り場で見かける「ロマネスコ」という野菜や、冬の「雪の結晶」、大きな「シダの葉」をじっくり観察したことはありますか？  
ロマネスコのとんがりを1つ切り取ってみると、それは**野菜全体の形とそっくりな小さなロマネスコ**になっています。さらにその中の小さないとんがりを虫眼鏡でのぞくと、やっぱり同じ形をしています。

このように、**「図形の一部を拡大していくと、全体と同じ形が繰り返し現れる性質」** のことを数学で **自己相似（Self-Similarity）** と呼び、そうした図形全体を **フラクタル（Fractal）** と呼びます。

```text
【全体】 大きな木 ──> 幹から2本の枝が伸びる
  └── 【一部】 枝の先端 ──> さらに小さな2本の枝が伸びる（全体とそっくり！）
        └── 【さらに一部】 そのまた先端 ──> もっと小さな2本の枝が伸びる！
```

##### 🐱 Scratch 学習者へのメッセージ: なぜフラクタルは描くのが難しいのか？
Scratch（スクラッチ）で猫のキャラクターを動かしたり、`[10 歩動かす]` や `[15 度回す]`、`[10 回繰り返す]` ブロックを使って正方形や星を描いたことがある人も多いでしょう。

しかし、Scratch で「枝分かれする木」を描こうとすると、こんな問題にぶつかります。
- 1段階目の枝を描くコードを書く
- 2段階目の小さな枝を描くコードをコピー＆ペーストして繋げる
- 3段階目の枝を描くコードをさらにコピー＆ペーストする……？？

これでは、枝が増えるたびにブロックが画面からあふれて収まらなくなってしまいますね。

ところが、数学とプログラミングには **「再帰（さいき / Recursion）」** という魔法のようなテクニックがあります。「自分の中に、自分と同じ仕組みを呼び出す」という、たった10行ほどのコードを書くだけで、コンピュータは**何千本もの細かな枝を持つ本物そっくりの美しい大木**を一瞬で描き出してくれます！

本書では、画面上をカメ（タートル）が進んで線を引く **タートルグラフィックス** を使い、次のような魅力的な図形を自分の手で作り上げていきます。

1. **基本の図形**: 正方形・多角形・きれいな渦巻き（準備運動）
2. **フラクタルツリー**: 自然な風合いを持つ枝分かれの木
3. **コッホ曲線・コッホ雪片**: まるで本物の雪の結晶のような幾何学模様
4. **シェルピンスキーの三角形**: 三角形の中に無限に三角形が潜む不思議な模様
5. **ドラゴン曲線**: 折り紙を何度も折って開いたときに現れる竜の形の曲線

高校数学で習う「図形と方程式」「三角比」「数列の規則性」が、プログラムの「関数」や「再帰」とバチッとつながる感動を、ぜひ体験してください！

#### 0.2 なぜ Racket か——ブロックから文字へ、構文より「論理」を学ぼう

##### 🧱 Scratch ブロックと Racket の括弧は同じもの！
Scratch などのブロック言語から、Python や C言語、Java などのテキスト（文字）言語に引っ越すとき、多くの人がつまずくポイントがあります。

- セミコロン `;` を押し忘れてエラーになる
- 中括弧 `{ }` やインデント（字下げ）のズレで動かない
- `public static void main(String[] args)` のような呪文の意味がわからない

プログラミングで本当に大切なのは、こうした「細かな文法のルール（作法）」ではなく、**「どういう順番で論理を組み立てるか」** という考え方そのものです。

本書で採用する **Racket（ラケット）** は、世界最高峰のプログラミング教育教科書 *How to Design Programs (HtDP)* のために開発された言語です。Racket の文法は、驚くほどシンプルで、基本的にたった1つのルールしかありません。

```racket
(演算子 引数1 引数2 …)
```

例えば、足し算ならこう書きます。
```racket
(+ 1 2)   ; 1 と 2 を足す。結果は 3
```

「括弧が多くて変だな？」と思いましたか？ 実は、Scratch のブロックと見比べてみてください。

- Scratch の `[ (1) + (2) ]` ブロック ──> Racket の `(+ 1 2)`
- Scratch の `[ (50) 歩動かす ]` ブロック ──> Racket の `(forward 50)`
- Scratch の `[ (90) 度回す ]` ブロック ──> Racket の `(turn-left 90)`

**Racket の括弧 `( )` は、Scratch の「ブロックの枠線」そのもの** なのです！  
開いて閉じる括弧の中に「やりたいこと（演算子）」と「データ（引数）」を並べるだけ。セミコロンも特殊な記号もいりません。だからこそ、文法エラーでイライラすることなく、純粋な「図形を描く論理」に集中できるのです。

#### 0.3 DrRacket と BSL／開発環境の見取り図

##### 🛠️ 開発環境 DrRacket を用意しよう
1. [Racket 公式サイト](https://download.racket-lang.org/) から環境に合ったインストーラをダウンロードしてインストールします。
2. アプリケーションから **DrRacket** を起動します。
3. **おすすめ設定**:
   - `Edit → Preferences`（Mac は `DrRacket → Preferences`）の `Display` タブで **Show line numbers（行番号を表示）** にチェックを入れます。

##### 🎓 学びのレベル分け（BSL と `#lang racket`）
DrRacket には初学者が安全に学べる「言語レベル」が用意されています。本書では以下のアプローチ（**言語方針 A**）をとります。

| 段階 | 使用する言語設定 | 何を学ぶか？ |
|---|---|---|
| **序盤（序章〜第1章）** | `#lang htdp/bsl` (Beginning Student) | 式の計算・関数の定義・自動テスト・リストの基礎 |
| **本編（第2章〜第4章）** | `#lang racket` + `teachpacks/racket-turtle` | カメへの命令リストを作ってフラクタルを描く |
| **発展（終章・付録 F）** | `#lang racket` + `plot` | データや数式の宣言的プロット・Headless 画像出力 |

※ `htdp/bsl` の **HtDP** は教科書 *How to Design Programs*、**BSL** は *Beginning Student Language*（初心者言語）の略です。

##### 💻 相互作用ウィンドウ（REPL）で遊んでみよう
DrRacket の画面は上下（または左右）に2つに分かれています。
- **定義ウィンドウ（上・左）**: プログラム全体をファイルとして書き保存する場所
- **相互作用ウィンドウ（下・右 / REPL）**: 1行コードを入れるとすぐその場で計算結果を返してくれる実験場

相互作用ウィンドウ（REPL: Read-Eval-Print Loop）に、次のように打ち込んで Enter キーを押してみましょう。

```racket
(+ 2 4)
; => 6 が表示される！

(+ 2 4 (* 5 5) (- (+ 3 3) 2) 1)
; 内側の括弧から順番に計算されて => 36 が表示される！
```

###### 💡 初心者が最初にやってしまうエラーのパターン
- `((+ 3 4))` ── 外側の括弧の先頭に「演算子」がないため、Racket が「何をすればいいの？」と混乱します。
- `(3 (+ 1 6))` ── `3` は数字であって命令（演算子）ではないためエラーになります。

**「括弧 `(` の直後には、必ず実行したい命令（関数や演算子）を書く」**。これだけを覚えておけば完璧です！
